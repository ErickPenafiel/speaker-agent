# Política de seguridad

Si encuentras una vulnerabilidad, **no abras un issue público**. Repórtala en
privado desde la pestaña *Security → Report a vulnerability* de este repositorio.

Nunca subas claves reales (`.env`, claves de Vapi/Retell, tokens de proveedores).
Solo se versionan los archivos `.env.example`. Todos los datos de la demo son ficticios.
